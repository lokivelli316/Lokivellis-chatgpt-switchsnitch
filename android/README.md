# Native Android observer
This is an additive companion to the existing private SwitchSnitch bridge and browser extension. It is not a replacement. It is limited to the ChatGPT Android package and does not capture conversation text. It can independently show a native mismatch or visibility warning. The existing frozen security rules still govern automated restoration; a stable, unique native chat ID is required. ChatGPT may expose no stable chat ID in its accessibility tree. In that case native mismatch alerts work when a model label is visible, but automated restoration remains unavailable; tap the alert and select the model manually. No backend identity is claimed. 
Install the APK from the native-android Actions artifact (debug signed, for operator testing). Open SwitchSnitch, enter the exact model label, port from ~/.switchsnitch/port and token from snitch-token, save, enable notifications and enable its accessibility service in Android Settings. Open ChatGPT. If the selector is not recognized, the status shows model-selector resource IDs where available; the exact selector ID can be configured. Do not use a chat title as a stable chat ID. The heartbeat alarm is inexact and Android can delay it in Doze; it is not a guarantee of uninterrupted monitoring. Termux must remain active. A YES or NO bridge decision continues to use the existing Termux notification actions and decision socket. The S24 gates, Hotkey Prompter overlay verification, and backend identity verification remain unpassed until actual target-device evidence is available.

Main-branch CI also publishes a debug APK and SHA-256 checksum in Releases to avoid the Actions artifact quota.
